# Express.js Signup Form using Cookies

A simple Express.js application that demonstrates user registration using HTML forms and cookies.

This project was created as part of my Full Stack Development (FSD) Practical.

---

## 📚 Concepts Covered

- Express.js
- HTML Forms
- POST Request
- Middleware
- express.urlencoded()
- cookie-parser
- Cookies
- Cookie Expiry
- req.body
- req.cookies
- res.cookie()
- res.clearCookie()
- res.redirect()

## 🚀 Installation

Clone the repository.

```bash
git clone https://github.com/yourusername/ExpressJS-Signup-Form-Cookies.git
```

Go inside the project.

```bash
cd ExpressJS-Signup-Form-Cookies
```

Install dependencies.

```bash
npm install
```

Run the application.

```bash
node server.js
```

---

## 🌐 Open in Browser

```
http://localhost:3000
```
